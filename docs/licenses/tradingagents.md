# TradingAgents attribution

Nova's Advise rail adapts the *idea* of a multi-agent equity debate
(fundamentals, news, sentiment, technical, bull/bear, trader, risk) from:

[TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents)

License: Apache License 2.0
Copyright (c) Tauric Research and contributors

Nova does **not** vendor that repository. Prompts, the worker, the SQLite
book, and the UI are original Nova code. Advise is advisory only and never
sends broker orders.
