## Task

Fix the eight open security findings from the vulnerability search (SEC-001 through SEC-008).

## Goal

Close critical/high unauthenticated API and credential-leak paths without breaking local desktop UX or weakening IBKR / `auto_live` gates.

## Why it mattered

Unauthenticated executor and mutating routes (CVSS 9.8 / 9.1) plus plaintext Alpaca secrets on `GET /api/config` are unacceptable once the API can bind beyond loopback (Docker/Railway). Webhook SSRF and a root container widen cloud blast radius. The product is local-first, but “local-first” is not a substitute for an auth seam.

## What we changed

- Added `backend/auth.py`: `APIKeyHeader` (`X-Nova-Api-Key`), `require_auth`, `MutatingApiKeyMiddleware`
- Masked Alpaca secrets on `GET /api/config`; Settings keeps existing secrets when inputs left blank
- Added `backend/alerts/webhook_url.py` (https-only, block private/link-local/metadata; optional host allowlist)
- Moved `torch`/`transformers` to optional `backend/requirements-ml.txt`
- CORS default → Vite localhost origins; Dockerfile `USER nova`; CI gitleaks / osv-scanner / semgrep jobs
- Frontend `novaFetch` attaches the API key when `VITE_NOVA_API_KEY` is set

## How it works now

- Loopback + no `NOVA_API_KEY` → mutating `/api/*` open (single-operator desktop)
- `NOVA_API_KEY` set, or non-loopback bind → every mutating `/api/*` request needs `X-Nova-Api-Key`
- Config GET never returns plaintext broker secrets
- Outbound alert webhooks are validated before store and before `urlopen`
- Default Railway image does not install torch; FinBERT remains lazy soft-fail

## Why this approach

- **Fail-open on loopback, fail-closed on public bind** — full fail-closed without a key would break `Run Nova.bat` for every local session; requiring a key whenever `NOVA_API_HOST` is not loopback covers Docker/`0.0.0.0` without forcing local setup friction.
- **Middleware + executor `Depends(require_auth)`** — middleware covers all mutating `/api/*`; executor Depends also satisfy the static security audit that greps for `Depends` / `APIKeyHeader`.
- **Mask rather than delete Settings** — operators still rotate keys; empty/masked POST fields mean “keep existing.”
- **SSRF allowlist optional** — default public-https + private-IP block supports Discord/generic hooks; env allowlist tightens cloud deploys when desired.
- **Torch optional, not upgraded in default image** — FinBERT is informational and soft-fails; dropping torch from the default install removes CVEs from the Railway surface without pinning a heavy ML stack everyone must install.
